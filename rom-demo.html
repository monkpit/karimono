🎮 Game Boy Emulator - ROM Loading Demo

📄 Loaded ROM Information

How to Use

  • Load ROM: Click the "Load ROM" button to select a Game Boy ROM file (.gb or .gbc)
  • Controls: Use keyboard controls to play the game
  • Emulation: Use Play/Pause/Reset buttons to control emulation

Game Boy Controls

A Button Z
B Button X
Select Right Shift
Start Enter

Direction Controls

Up ↑ / W
Down ↓ / S
Left ← / A
Right → / D

Demo Information

Resolution: 160×144 pixels (Game Boy DMG)

Scale: 3x for modern displays (480×432)

Architecture: EmulatorContainer + EmulatorControls + ROMLoader + InputHandler

ROM Support: Game Boy (.gb) and Game Boy Color (.gbc) files

Features: Drag & drop ROM loading, keyboard controls, emulator state management
